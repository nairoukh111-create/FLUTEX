Cutting tool specification and RFQ checklist

A tool request should identify the geometry and mounting details separately from the material and operation. Use this checklist to turn a photograph or a short description into a quotation that can be checked.

In this guide

  2. Use the dimensions for the correct tool family
  3. Keep similar dimensions separate
  4. Ask for application data after identifying the tool
  5. What should the quotation confirm?
  6. Can a photo replace a drawing?
  7. Which coating is best for all aluminum work?

Published: 24 October 2026

Begin with the job and machine

Record the work material and grade, operation, machine model, holder interface and quantity. For aluminum, give the known alloy and condition rather than only writing aluminum. State whether the job is slotting, profiling, drilling or another operation, and identify any access or reach constraint.

If you are replacing an existing tool, include its reference and a drawing or photographs with dimensions. Mark which dimensions are measured and which are still unknown. Do not treat a rough measurement of a worn edge as a finished specification.

Use the dimensions for the correct tool family

FamilyInformation to include
Carbide end millCutting diameter, cutting length, overall length, shank diameter, flute count, end geometry and required radius. Identify coating by its documented designation.
HSS drillDiameter, flute and overall lengths, straight or taper shank, full standard/reference and stated HSS grade if known. A grade name alone is not a complete drill specification.
Modular drillHolder reference, insert reference or seat identification, required diameter and depth, and coolant arrangement. Confirm the holder/insert combination before substituting.
Saw bladeOutside diameter, cutting kerf, plate thickness, bore, tooth count and any pin-hole pattern. Add the machine model and the markings from the existing blade.
Tool holder or colletMachine interface and exact variant, holder reference, tool shank diameter, collet system/range, projection and coolant requirements.

Keep similar dimensions separate

Cutting diameter and shank diameter are separate fields. So are saw kerf and plate thickness, and cutting length and overall length. Give units on the drawing; do not assume an unlabelled value is in millimetres.

For a special tool, provide a controlled drawing with revision, required tolerances and the mating feature where relevant. Highlight the dimensions that determine fit and state which can be proposed by the supplier.

Ask for application data after identifying the tool

Ask the tool manufacturer for cutting speed, feed per tooth, engagement and lubrication suited to the exact tool and operation. The FLUTEX RPM/feed calculator converts supplied inputs; it does not choose them. It is a milling calculation resource, not an operating-speed approval for a saw blade.

For a comparison trial, record the tool identity, material, machine, holder, programmed values, engagement, lubrication and acceptance criteria. Comparing an undocumented new trial with a remembered tool life does not establish equivalent performance.

What should the quotation confirm?

  • Exact offered geometry, material/grade and coating or finish.
  • Drawing/reference revision and any proposed difference.
  • Quantity, packaging, destination and requested delivery date.
  • Availability or manufacturing lead time as confirmed by the supplier.
  • Application information still required before recommending operating values.

FLUTEX's listed families help organize the enquiry. They do not confirm that every size, coating or holder combination is held in stock.

Can a photo replace a drawing?

A clear photo is useful for identification. A drawing or confirmed dimensions are still needed for features that determine fit, reach or geometry. Tell us when a dimension is uncertain rather than selecting the nearest-looking family.

Which coating is best for all aluminum work?

This checklist does not select a universal coating. Identify the alloy, operation, geometry and lubrication, then request a documented recommendation for the offered tool.
