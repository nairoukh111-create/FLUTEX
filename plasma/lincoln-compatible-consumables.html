Lincoln compatible consumables — frequently asked questions

Which Lincoln plasma systems does FLUTEX cover?

FLUTEX covers 5 Lincoln system families: Tomahawk 1025 / Tomahawk 1538 / LC65 / LC65M / LC65M Gear Rack, Tomahawk 1025 / Tomahawk 1538 / LC105 / LC105M / LC105M Gear Rack, FlexCut 125, Tomahawk 1500 and Spirit 150A / Spirit 275A / Spirit 400A. Each system has its own page listing the original reference numbers covered.

How many original Lincoln reference numbers are covered?

Approximately 149 original Lincoln reference numbers are covered across these systems, spanning electrode, gas diffuser, inner retaining cap, insulator, nozzle, outer retaining cap, retaining cap, shield, shield cap, spacer, swirl ring, torch parts and water tube.
