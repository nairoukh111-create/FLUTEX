SL60 / SL100 consumables — frequently asked questions

Which consumables does FLUTEX supply for the Thermal Dynamics SL60 / SL100?

FLUTEX supplies compatible shield cup, shield cap, tip, start cartridge, electrode, o-ring and standoff guide for the Thermal Dynamics SL family, covering hand torch, cutting and gouging configurations. SL60/SL100 replacement torch consumables from electrode and start cartridge to cutting/gouging tips.

Are the original Thermal Dynamics part numbers for the SL60 / SL100 cross-referenced?

Yes. This range covers 56 original Thermal Dynamics reference numbers for the SL60 / SL100, including 35-1016, 35-1027, 35-1028, 35-1041 and others listed on this page. Send the original reference and FLUTEX confirms the compatible replacement in writing before quotation. Send the original reference number, the system model (SL60 / SL100), the operating amperage, the process (hand torch, cutting or gouging) and the required quantity. That is enough for FLUTEX to match the part and return price and lead time.
